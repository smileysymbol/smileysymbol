### Обо мне:
**QA-инженер** с бэкграундом в IT: почти 3 года работал аккаунт-менеджером в Travel-домене. На учебных проектах наработал крепкую базу с инструментами тестирования, а навыки автоматизации практикую в пет-проектах, где пишу код на Python с использованием фреймворков. Я привык структурировать информацию и веду подробные личные конспекты по всему, что изучаю, — эта привычка поможет поддерживать тестовую документацию на проекте понятной и актуальной. В работе люблю глубоко погружаться в продукт, а при столкновении с проблемой — сначала пытаюсь самостоятельно докопаться до причины и только потом обращаюсь за помощью к команде. Искренне люблю разбираться в сложной логике и понятно объяснять её другим.

 **Что умею:** 
- Составлять тестовую документацию (чек-листы, тест-кейсы, баг-репорты) в Qase.io/TestIT и Jira
- Тестировать веб-приложения (функциональное/нефункциональное тестирование, DevTools: Elements, Network, Console, Application)
- Работать с API (Postman, REST/SOAP, авторизация, сниппеты, ассерты)
- Писать SQL-запросы (JOIN-ы, агрегатные функции, вложенные запросы) в DBeaver/pgAdmin
- Анализировать логи в Kibana (поиск по trace ID, чтение ошибок)
- Развертывание окружений через docker-compose, базовое управление контейнерами (запуск/остановка/удаление), сборка образов, очистка ресурсов.
- Использовать Linux (Ubuntu): навигация, файлы, права доступа, процессы, потоки ввода-вывода
- Работать с Git (clone, commit, push, branch и др.)
- Знаю теорию Kafka (топики, партиции, продюсеры/консьюмеры, гарантии доставки)
